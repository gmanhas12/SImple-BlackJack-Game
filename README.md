A fully functional Blackjack game built using JavaScript, HTML, and CSS. This project simulates a real-world casino-style Blackjack experience with dynamic visuals and intuitive gameplay. Perfect for both learning and entertainment!

Features
Core Gameplay Mechanics:

Player and dealer card dealing, hitting, and standing logic.
Automated dealer actions (hits until reaching 17 or higher).
Real-time score calculation and display.
Advanced Features:

Multi-deck gameplay using a six-deck shoe.
Blackjack detection for both player and dealer, with automatic win/loss messages.
Interactive user interface with dynamically rendered cards and score updates.
Accurate game-ending logic for busts, dealer wins, ties, and player wins.
Polished User Experience:

Face-down dealer card is flipped only when appropriate (e.g., dealer's turn or blackjack).
Smooth animations and delays for realism, creating a lifelike game flow.
Clear visual feedback for game results (e.g., alerts for wins, losses, or ties).
How to Play
Start the Game:
Click the "Start" button to begin. The player and dealer are each dealt two cards.

Player Actions:

Hit: Take another card.
Stand: End your turn and let the dealer play.
Winning Conditions:

A blackjack (21) wins immediately for the player or dealer.
The closest to 21 without going over wins the round.
If both have the same score, it's a tie.
Dealer Logic:

The dealer reveals their face-down card on their turn.
The dealer continues to hit until their score is at least 17.
End Game:
The game announces the result (Player Wins, Dealer Wins, Tie, or Blackjack) and resets for the next round.

Setup
To run this game locally:

Clone the repository and open the index.html file in your browser.
